The Framework includes several zeus modules to handle mid-mission functions, and general mission flow.

This section covers each module, with a brief explanation as to what it does, and any tips, tricks or things to be aware of.


## [MISC] Countdown Timer

This module allows the display of a custom countdown timer. The countdown length can be customised, as can the messages that display whilst the countdown is active and when it finishes.

Unlike the vanilla countdown timer, this timer will not end the mission automatically upon completion, so it can be used for things like timed objectives, timed breaks etc.


## [RALLY] Assign Leader Roles

This module allows the assigning and removal of squad leader and platoon leader roles. Using this module can give rally point actions to individual players as and when needed. THis can be useful if a player in a leadership role has to drop out of the session and be replaced by another player.
