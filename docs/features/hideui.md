# UI Hider

*Adds a rally point system that allows players to teleport to and from squad-level and platoon-level rally points*

---

## ✅ Purpose

This system gives players an easy option to hide vanilla/modded UI.


---

## ⚙️ How It Works

The option is always available to players via the ACE self-interaction menu. It will toggle all vanilla and (most) modded UI elements to allow players to take clutter-free screenshots.

---

## 🛠️ Mission Maker Usage

There is no requirement for the mission maker to enable this system, or configure anything.


---

## 📦 Dependencies


- CBA_A3
- ACE
